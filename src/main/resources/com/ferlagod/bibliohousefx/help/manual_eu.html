Erabiltzailearen Eskuliburua - BiblioHouse

Ongi etorri BiblioHouse-ra, zure liburutegi pertsonaleko kudeatzailera. Aplikazio honek zure liburu-bilduma antolatzeko, maileguak kudeatzeko eta zure irakurketen jarraipena egiteko aukera ematen dizu.

📚 Liburuen Kudeaketa

Liburuak Gehitu

Liburuak bi modutara gehi ditzakezu:

  • Automatikoa (OpenLibrary): Idatzi izenburua edo ISBN goiko barran eta sakatu Enter edo lupa. Liburua aurkitzen baduzu, sakatu "Gehitu".
  • Eskuz: Bete eremuak (Izenburua, Egilea, ISBN...) "Eskuz gehitu" panelean eta sakatu "Gehitu Liburutegira".

Editatu eta Ezabatu

Egin klik eskuineko botoiarekin taulako edozein libururen gainean aukerak ikusteko:

  • Editatu xehetasunak: Aldatu liburuaren informazioa.
  • Aldatu azala: Eguneratu azalaren irudia.
  • Ezabatu liburua: Ezabatu liburua betiko zure bildumatik.

🔄 Maileguak

"Mailegu Aktiboak" fitxan zure liburuak lagunei edo senideei (Bazkideak) mailegatu ahal dizkiezu.

  1. Aukeratu Liburu erabilgarri bat.
  2. Aukeratu Bazkide bat (edo sortu berri bat + botoiarekin).
  3. Sakatu Mailegua Egin.

Liburua itzultzen dizutenean, aukeratu beheko taulan eta sakatu Markatu Itzulita gisa.

⌨️ Teklatuko Lasterbideak

Handitu zure produktibitatea lasterbide hauekin:

  • Ctrl + F : Bilatu liburua (Fokua izenburuaren iragazkian).
  • Ctrl + N : Gehitu eskuzko liburu berria (Fokua izenburuan).
  • Ctrl + L : Egin mailegua (Fokua liburuaren aukeraketan).
  • Ctrl + Q : Irten aplikaziotik.
Oharra: macOS-en, erabili Cmd ⌘ tekla Ctrl-en ordez.
