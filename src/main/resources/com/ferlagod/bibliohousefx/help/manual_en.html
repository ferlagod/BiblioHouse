User Manual - BiblioHouse

Welcome to BiblioHouse, your comprehensive solution for personal library management. This detailed guide will help you get the most out of every feature, from cataloging books to managing loans and members.

1. Getting Started

When you start BiblioHouse, you will see the main dashboard. The interface is designed to be intuitive and is divided into tabs for easy navigation:

  • Catalog (Table/Gallery): Your complete collection of books.
  • Loans: Active management of lent books.
  • History: Historical record of all transactions.
Note: You can customize the application language at any time from Tools > Settings or from the Language menu.

2. Book Management

Adding Books

BiblioHouse offers three powerful methods to add books to your collection:

A. Unified Automatic Search

The fastest way. BiblioHouse searches simultaneously on OpenLibrary, Google Books, and Inventaire.

  1. Go to the "Catalog" tab.
  2. In the top bar (Online Search), type the title, author, or ISBN.
  3. Press Enter or click the magnifying glass icon.
  4. A window with search results will appear. Select the correct book and click "Add".

B. Barcode Scanning

Ideal if you have the physical book. Uses your computer's webcam.

  1. Click the button with the Camera/Barcode icon.
  2. Show the book's barcode (ISBN) to the camera.
  3. The system will automatically detect the code, close the window, and fill in the book data by searching online.

C. Manual Entry

For old or rare books not found online.

  1. Fill in the fields on the left sidebar: Title, Author, Publisher, Genre, etc.
  2. If the book belongs to a saga, indicate the Series name and Order (e.g., "Harry Potter", 1).
  3. You can drag a cover image directly onto the image box or click "Select Cover".
  4. Click Add to Library.

Editing and Organizing

  • Edit: Double-click on any book in the list to open the full editor. You can modify all data, change the shelf, or update the cover.
  • Organize by Shelves: Assign books to custom "Shelves" (e.g., "Favorites", "Sci-Fi") from the edit menu. Use the left sidebar to filter your view by shelf.
  • Multiple Stock: If you have multiple copies of the same book, BiblioHouse manages the quantity. When deleting, it will ask if you want to remove one unit or the entire record.

3. Member Management

To lend books, you first need to register people (Members).

  1. Go to the menu Members > Member Management.
  2. Use the form to register a new member (Name, ID, Phone...).
  3. From this window, you can also edit contact details or delete members (provided they have no pending books to return).

4. Loan System

Making a Loan

  1. Go to the Loans tab.
  2. In the "New Loan" panel, select the book from the dropdown (only books in stock are shown).
  3. Select the member who is taking the book.
  4. Click Make Loan.

Returns and Due Dates

In the bottom table, you will see all active loans.

  • Return: Select the loan row and click Mark as Returned. The book will become available in your stock again.
  • Overdue Alerts: If a loan exceeds the configured time limit (default is 30 days), the row will be marked in red and you will receive an alert upon opening the application.

5. Advanced Tools

Backups

Protect your data. Go to Tools > Settings.

  • Export Backup (ZIP): Creates a compressed file with all your data and covers. Ideal for moving your library to another computer.
  • Import/Export JSON: From the File menu, you can export only book data in lightweight JSON format or import an external database.

PDF Reports

Generate professional catalogs of your library. Go to File > Export to PDF. You can filter by shelf or genre before generating the document.

6. Keyboard Shortcuts

Boost your productivity with these quick shortcuts:

  • Ctrl + F : Search in my library (Focus on local filter).
  • Ctrl + N : New book (Focus on manual form).
  • Ctrl + L : Go to Loans tab.
  • Ctrl + Q : Quit application.
On macOS, use the Cmd ⌘ key instead of Ctrl.
