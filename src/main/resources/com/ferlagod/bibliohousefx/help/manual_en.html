User Manual - BiblioHouse

Welcome to BiblioHouse, your personal library manager. This application allows you to organize your book collection, manage loans, and track your reading.

📚 Book Management

Adding Books

You can add books in two ways:

  • Automatic (OpenLibrary): Type the title or ISBN in the top bar and press Enter or the search icon. If found, click "Add".
  • Manual: Fill in the fields (Title, Author, ISBN...) in the "Add manually" panel and click "Add to Library".

Edit and Delete

Right-click on any book in the table to see options:

  • Edit details: Modify book information.
  • Change cover: Update the cover image.
  • Delete book: Permanently remove the book from your collection.

🔄 Loans

In the "Active Loans" tab, you can lend your books to friends or family (Members).

  1. Select an available Book.
  2. Select a Member (or create a new one with the + button).
  3. Click Make Loan.

When the book is returned, select it in the table below and click Mark as Returned.

⌨️ Keyboard Shortcuts

Boost your productivity with these shortcuts:

  • Ctrl + F : Search book (Focus on title filter).
  • Ctrl + N : Add new manual book (Focus on title).
  • Ctrl + L : Make loan (Focus on book selection).
  • Ctrl + Q : Exit application.
Note: On macOS, use the Cmd ⌘ key instead of Ctrl.

⚙️ Settings

Go to Tools > Settings to change the visual theme (Light, Dark, Green...), language, and default loan duration.
